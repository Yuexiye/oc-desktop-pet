> ⚠️ **结论**：skip-if-missing 的探测对象必须是**模型运行时实际参数**，不能只查 `dir(StandardParams)` 枚举——`_FakeModel` 的缺参是通过 `SetParameterValue` 运行时抛异常模拟的（真实 live2d 模型同样如此：对不存在的 param id 调用 SetParameterValue 会抛/失败）。

### 5.3 live2d-py 官方 API（已查证 Arkueid/live2d-py）

- 缺参数探测正解：`for i in range(model.GetParameterCount()): p = model.GetParameter(i); p.id/p.min/p.max/p.default` → 得到模型**实际** param id 集合
- `model.SetParameterValue("ParamId", value, weight)`：weight 语义 = 最终值 = 原值*(1-weight) + 传入值*weight；**对模型不存在的 param id 调用会失败**
- 默认参数 id 从 `live2d.v3.params.StandardParams`（即 `self._live2d.StandardParams`）取，属性值为字符串 id
- 本项目 import 方式：`avatar/live2d_renderer.py:530` 起 `import live2d.v3 as l2d`，`self._live2d = l2d`（懒加载，GL 就绪后）
- 自定义参数（水印 Param261 等）用裸字符串 id 直接 SetParameterValue —— 这是 T08 的 special_params 素材

## 7. 红线与历史坑（血泪教训，违者自付）

### 7.1 沙箱 `git rm -r` 灾难（已发生一次）
- 本环境执行 `git rm -r --quiet <paths>` 会把**整个工作树从磁盘清空**（只把点名删除 staged），曾差点连 `core/play/`、`core/perception/` 一起没了
- 恢复：`git checkout -- .`（index → worktree）；锚点 tag `pre-orphan-delete` = `e93ea73`
- **以后删除一律：先确认要删的路径清单 → 用 `git rm`（尽量不带 `-r`）或直接删文件再 `git add -A`，且每步 `git status` 复核**

### 7.2 方法级裸 `except Exception: pass` 吞真 bug（oc-pet 已知教训）
- 曾因 `_override` 漏定义 NameError 被静默吞掉，导致整个程序化表情层失效几天
- T07 消灭 13 处该类 catch 的意义正在于此；param_writer 里也**不许**再写宽泛吞异常的兜底

### 7.3 Live2D wrapper 行为（T08 必读）
- `StartMotion` 不自动打断正在播的 motion；`StopAllMotions` 某些 wrapper 需**双重调用**
- miku 比心/葱/唱歌是 Param131-137 贴图开关（`SetExpression`），单/双次 `ResetExpressions` 特定状态仍可能残留（曾致「重置后心形还在」）
- 撤销 `b1f543c`「非 idle 禁止叠加表情」会复现「比心+举葱」叠加 → **T08 mixer 必须保留 `_force_idle` 的三重 `ResetExpressions` + 双重 `StopAllMotions` 作为强制重置最后防线**，仲裁只在上层做
- 高频 `set_emotion` 洪流防闪烁：沿用 `3be390a` 的「重置后 3 秒冷却」
- 右键「模型动作」手动面板已删除（dd5342f），`_override` 恒 False——**不要尝试复活该面板**
