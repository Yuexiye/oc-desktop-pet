# 添加桌宠角色（Live2D / 精灵图）教程

> 适用版本：oc-pet 当前主分支。
> 角色目录约定：`characters/<角色id>/`，一个目录 = 一个角色包。

---

## 一、两种角色格式总览

| 格式 | 目录结构 | 特点 |
|---|---|---|
| **Live2D** | `characters/<id>/live2d/*.model3.json` + `moc3` + `textures/` + `motions/` | 表情/动作丰富，推荐 |
| **精灵图** | `characters/<id>/frames/<动作>/<动作>_N.png` | 序列帧，简单直接 |

角色格式由 `pet.json` 里的 `"format"` 字段决定：
- `"live2d"` → Live2D 渲染器
- `"sprite"` / `"q6"` → 帧精灵渲染器
- 不写则自动检测（有 `live2d/*.model3.json` 就是 live2d，否则按精灵图）

---

## 二、导入 Live2D 模型（推荐）

### 1. 准备工作
1. 获取一个**有分发许可**的 Live2D 模型（`.moc3` + 纹理 + `.model3.json`）。
   - 免费模型源：Live2D 官方 [CubismWebSamples](https://github.com/Live2D/CubismWebSamples)（Haru / Hiyori 等）
   - 或运行 `python tools/fetch_free_live2d_sample.py` 一键拉取官方样例到 `characters/sample_live2d/`
   - 社区免费模型（如本机的 `miku`）注意阅读作者的许可证，**商用/二传需谨慎**
2. 解压拿到：`xxx.moc3`、`xxx.model3.json`、纹理图片（png）、可能还有 physics/表情 json。

### 2. 复制到角色目录
把模型文件放入 `characters/<id>/live2d/`，按下面的标准结构整理：

```
characters/miku/
├── pet.json                      ← 角色元数据（必填，见下）
├── identity.md                   ← 可选，角色身份描述
└── live2d/
    ├── miku.moc3                 ← 模型本体
    ├── miku.model3.json          ← 模型清单（moc/纹理/动作/表情引用）
    ├── miku.physics3.json        ← 物理效果（可选）
    ├── miku.cdi3.json            ← 显示信息（可选）
    ├── textures/                 ← 纹理放这里
    │   ├── texture_00.png
    │   └── ...
    ├── motions/                  ← 动作放这里
    │   ├── idle.motion3.json
    │   └── ...
    └── expressions/              ← 表情放这里（可选）
        ├── 比心.exp3.json
        └── ...
```

### 3. 修正 model3.json 的引用路径
原模型的 `.model3.json` 里纹理/动作路径可能指向原目录结构，需要改成相对 `live2d/` 的路径。参考：

```json
{
  "Version": 3,
  "FileReferences": {
    "Moc": "miku.moc3",
    "Textures": [
      "textures/texture_00.png",
      "textures/texture_01.png"
    ],
    "Motions": {
      "": [
        { "File": "motions/idle.motion3.json" },
        { "File": "motions/happy.motion3.json" }
      ]
    },
    "Expressions": [
      { "Name": "比心", "File": "expressions/比心.exp3.json" }
    ]
  },
  "Groups": [
    { "Target": "Parameter", "Name": "LipSync", "Ids": [] },
    { "Target": "Parameter", "Name": "EyeBlink", "Ids": ["ParamEyeROpen", "ParamEyeLOpen"] }
  ]
}
```

> ⚠️ **动作/表情文件名要带英文关键词**：渲染器按文件名匹配情绪。
> 例如 `idle.motion3.json`、`happy.motion3.json`、`angry.motion3.json` ——
> 情绪 `happy` 会优先找文件名含 `happy/joy/smile` 的动作/表情。
> 表情名是中文也能匹配，见最后的"情绪映射表"。

### 4. 写 pet.json
```json
{
  "id": "miku",
  "name": "初音未来",
  "description": "模型作者信息",
  "style": "live2d",
  "format": "live2d",
  "live2d": {
    "scale": 1.0,
    "offset": [0, 0]
  },
  "scale": 1.0
}
```

### 5. 启用角色
在桌面宠物设置面板 → 基础 Tab → agent 列表 → 勾选启用新角色；或右键桌宠 → 设置 → 角色包管理里确认。

## 三、导入精灵图角色

### 1. 准备序列帧
把每个动画拆成一组 PNG，命名规范 `动作名_序号.png`（从 0 开始）：

```
characters/mycoolpet/
├── pet.json
└── frames/
    ├── idle/
    │   ├── idle_0.png
    │   ├── idle_1.png
    │   └── ...
    ├── running/
    │   ├── running_0.png
    │   └── ...
    └── waving/
        ├── waving_0.png
        └── ...
```

### 2. 写 pet.json
`animations` 里每个动作声明：起始行 `row`、帧数 `frames`、播放速度 `fps`。
`emotions` 把情绪映射到动作；`neutral` 必填。

```json
{
  "id": "mycoolpet",
  "name": "我的宠物",
  "description": "……",
  "style": "flat",
  "format": "sprite",
  "animations": {
    "idle":         { "row": 0, "frames": 6, "fps": 3 },
    "running":      { "row": 1, "frames": 6, "fps": 5 },
    "waving":       { "row": 2, "frames": 4, "fps": 4 },
    "jumping":      { "row": 3, "frames": 5, "fps": 5 },
    "failed":       { "row": 4, "frames": 8, "fps": 4 },
    "waiting":      { "row": 5, "frames": 6, "fps": 3 }
  },
  "emotions": {
    "happy":     { "anim": "waving" },
    "surprised": { "anim": "jumping" },
    "thinking":  { "anim": "waiting" },
    "sad":       { "anim": "failed" },
    "angry":     { "anim": "running" },
    "neutral":   { "anim": "idle" }
  },
  "scale": 1.0
}
```

### 3. 可选：spritesheet.webp
整图精灵（单张 atlas）放 `characters/<id>/spritesheet.webp`，pet.json 用
行/列定义帧位。项目原生有两个角色都用精灵图，参考 `characters/yuexinmiao/pet.json`。

## 四、情绪 → 动作/表情映射

| 情绪 | Live2D 文件名关键词（动作） | Live2D 文件名关键词（表情） | 精灵图动画键 |
|---|---|---|---|
| happy | happy / joy / smile / fun / 唱歌 / 比心 | 同左 | waving |
| angry | angry / mad | (可加) | running |
| sad | sad / cry | (可加) | failed |
| surprised | surprise / shock / 圈圈 / 前倾 | 同左 | jumping |
| thinking | think / doubt / 圈圈 / 前倾 | 同左 | waiting |
| cute | (可加 脸红) | 脸红 | - |
| neutral | idle | — | idle |

> 映射表在 `avatar/live2d_renderer.py` 的 `_EMOTION_KEYWORDS` / `_ANIM_TO_MOTION_KW`。
> 想自定义就在这里加关键词。

## 五、常见问题

- **模型加载失败/白屏**：看日志 `logs/oc_pet.log` 里 `Live2DRenderer: 模型加载失败: ...`。
  常见原因：model3.json 引用路径不对、moc3 版本与 live2d-py 不兼容（推荐 Cubism 3/4 模型）。
- **表情不切换**：确认 `model3.json` 有 `Expressions` 段，且表情文件名含对应情绪关键词。
- **动作不循环**：`motions/` 下要有 `idle.motion3.json`（待机动作）。
- **改完不生效**：重启桌宠；切换渲染格式（设置面板 → 格式）后也需重启。
- **模型版权**：live2d/ 目录已在 `.gitignore` 排除，不会进 git；但商用和二次分发仍要遵守模型作者许可。

## 六、用命令行快速验证

```bash
# 检测角色格式是否识别
python -c "from avatar.factory import detect_format; print(detect_format('miku'))"
# 预期输出: live2d

# 枚举已安装角色包
python -c "from core.character_package import CharacterPackageManager; print([p.agent_id for p in CharacterPackageManager().list_installed_packages()])"
```

参考实现：`characters/miku/`（Live2D）、`characters/yuexinmiao/`（含精灵图）。
