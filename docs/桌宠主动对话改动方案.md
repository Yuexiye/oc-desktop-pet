## 一、背景与目标

### 1.1 当前问题

桌宠的主动对话逻辑存在以下问题：

1. **触发源分散**：proactive、idle、idle chatter、屏幕感知四个触发源各走各的，没有统一调度，容易冲突和重复。
2. **内容尴尬**：proactive 没有注入 Hana 的记忆（`inject_memory=False`），LLM 在无上下文时生成"感到寂寞"这类泛泛内容。
3. **过度打扰**：没有每日上限、没有时段感知、没有静默模式，用户随时可能被骚扰。
4. **不可观测**：没有触发日志，出问题无法定位，优化靠猜测。

### 1.2 目标

1. **不尬**：宁可沉默，不可尴尬。内容池里必须有黑词过滤。
2. **不撞**：用户正在打字、开会、看视频时，桌宠一律闭嘴。
3. **可解释**：用户能知道"它什么时候会说话、怎么关掉、为什么这句出现了"。
4. **可观测**：所有调度决策打日志，出问题能查。

### 3.2 触发请求入口

```python
class DialogueScheduler:
    """统一调度器（单例，线程安全）"""
    
    def request(self, trigger_source: str, priority: str, payload: dict) -> Optional[str]:
        """
        请求触发一次主动对话。
        
        Args:
            trigger_source: 触发源（proactive / idle / idle_chatter / screen）
            priority: 优先级（high / low）
            payload: 上下文（场景标签、记忆、用户状态等）
        
        Returns:
            生成的文本（如果允许触发），或 None（如果放弃触发）
        """
        # 1. 静默模式检查
        if self._is_dnd_active():
            return None
        
        # 2. 打扰预算检查
        if not self._has_budget_remaining():
            return None
        
        # 3. 并发互斥检查
        if self._is_user_busy():
            return None
        
        # 4. 幂等去重（5 秒内同源触发合并，同源 60 秒内只放行一次）
        if not self._is_trigger_allowed(trigger_source):
            return None
        
        # 5. 优先级判断
        if priority == "high":
            # 系统提示：模板直出，不走 LLM，不占预算
            return self._generate_template(payload)
        else:
            # 主动聊天：LLM 生成，注入记忆，占预算
            return self._generate_llm(payload)
```

### 3.3 静默模式（Do Not Disturb）

```python
def _is_dnd_active(self) -> bool:
    """检查是否处于静默模式"""
    # 1. 用户手动开启勿扰
    if self._dnd_manual:
        return True
    
    # 2. 用户正在打字（前台窗口是 IDE / 浏览器 / 聊天软件）
    if self._is_user_typing():
        return True
    
    # 3. 用户正在看视频（全屏窗口）
    if self._is_fullscreen_video():
        return True
    
    # 4. 用户正在开会（检测到会议软件前台）
    if self._is_in_meeting():
        return True
    
    # 5. 深夜时段（00:00-08:00）
    if self._is_late_night():
        return True
    
    return False
```

### 3.4 打扰预算

```python
def _has_budget_remaining(self) -> bool:
    """检查是否有剩余打扰预算"""
    # 每日上限：默认 6 次/日
    if self._daily_count >= self._daily_limit:
        return False
    
    # 时段分配：工作时段 4 次、休闲时段 2 次、深夜 0 次
    period_limit = self._get_period_limit()
    if self._period_count >= period_limit:
        return False
    
    # 冷启动保护：新安装用户前 24 小时预算减半
    if self._is_cold_start():
        return self._daily_count < self._daily_limit // 2
    
    return True
```

### 3.5 并发互斥

```python
def _is_user_busy(self) -> bool:
    """检查用户是否正在忙"""
    # 1. 用户正在 Hana 主对话窗口
    if self._is_hana_chat_active():
        return True
    
    # 2. 用户正在输入（打字检测）
    if self._is_user_typing():
        return True
    
    # 3. 用户正在快速操作（鼠标移动频率高）
    if self._is_user_active():
        return True
    
    return False
```

### 3.6 失败降级

```python
def _generate_llm(self, payload: dict) -> Optional[str]:
    """LLM 生成（带失败降级）"""
    try:
        # 1. 尝试 LLM 生成
        text = self._adapter.chat(
            prompt=payload["prompt"],
            inject_memory=True,  # 关键：注入记忆
            source="proactive",
        )
        
        # 2. 内容校验
        if not self._validate_content(text):
            return None
        
        return text
        
    except Exception as e:
        # 3. LLM 失败，走模板库
        logger.warning("LLM 生成失败，降级到模板库: %s", e)
        return self._generate_template(payload)
```

### 3.7 内容过滤

```python
def _validate_content(self, text: str) -> bool:
    """内容校验（黑词过滤 + 长度检查 + 重复检查）"""
    # 1. 长度检查（< 3 字跳过）
    if len(text) < 3:
        return False
    
    # 2. 黑词过滤（寂寞、孤单、想你等）
    black_words = ["寂寞", "孤单", "想你", "感到寂寞", "有点寂寞"]
    if any(w in text for w in black_words):
        return False
    
    # 3. 重复检查（和最近 N 次内容相似度 > 阈值跳过）
    if self._is_duplicate(text):
        return False
    
    return True
```
